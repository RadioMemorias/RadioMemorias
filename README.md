# Radio Memorias

Sitio web estático listo para GitHub Pages.

## Publicar
1. Crea un repositorio público llamado `TUUSUARIO.github.io` (reemplaza TUUSUARIO por tu usuario de GitHub).
2. Sube `index.html` a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch, rama `main`, carpeta `/ (root)` y guarda.
4. Espera unos minutos y visita `https://TUUSUARIO.github.io/`.

## Activar el reproductor
La página está preparada visualmente, pero no puede emitir audio hasta tener una URL de streaming compatible (por ejemplo, Icecast o Shoutcast). Cuando tengas esa URL, se puede agregar un reproductor HTML5 con `<audio>`.
