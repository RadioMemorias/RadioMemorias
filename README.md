# Radio Memorias

1. Descomprime el archivo ZIP.
2. Sube `index.html` a tu repositorio de GitHub Pages, reemplazando el archivo anterior.
3. Confirma los cambios con **Commit changes**.

La página enlaza con el canal y la sección de directos de YouTube. Para mostrar un reproductor integrado dentro de la página, hace falta la URL de una transmisión concreta.
