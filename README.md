# Radio Memorias

Página web de Radio Memorias con enlaces al canal y a las transmisiones en vivo de YouTube.

## Publicar en GitHub Pages
1. Descomprime este ZIP.
2. Sube `index.html` a tu repositorio y reemplaza el archivo anterior.
3. Confirma con **Commit changes**.

Nota: el botón de YouTube abre el canal y la sección de directos. Para insertar el reproductor dentro de la página se necesita la URL de una transmisión específica.
